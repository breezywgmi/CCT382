# CCT382 Milestone 1: Character Controller

A third-person character controller in a grey-box test course, made in Unity 6 (URP).

## How to run
1. Open the project in Unity 6 (URP).
2. Open `Assets/Scenes/Milestone1_Gym.unity` and press Play.

## Controls
- Move: WASD or left stick (always runs)
- Jump: Space or gamepad south button
- Crouch (hold): Ctrl, C, or gamepad east button
- Camera: mouse or right stick

## What is in it
- New Input System (keyboard/mouse and gamepad)
- Humanoid character with an Animator Controller: idle/walk/run blend tree, plus jump, fall and crouch states
- Cinemachine FreeLook-style camera with damping and dead zones, and a light breathing noise
- Dust particle effect at the character's feet
- Grey-box test course: run lane, steps and ramp, height blocks, and a low ceiling that needs a crouch
